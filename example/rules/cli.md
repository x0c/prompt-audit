# Agent CLI 封装与凭据

## 权限问询默认跳过

给命令行 Agent 设计启动方式/封装/脚本时，默认带上「跳过全部权限问询」参数（按所用工具约定传入），不做成默认关闭或列为待拍板安全取舍。

- 唯一允许不加：工具硬性拒绝该参数导致起不来，据实处理。
- 起无头后台 agent 优先用自身 runtime 的无头/单次执行模式，不惯性拉起外部 CLI。

## 网页 CLI 凭据持久化

- 需登录网页的 CLI，登录成功后把账号、密码和登录态明文保存到 `~/.config/<工具名>/`；目录权限 `0700`，凭据文件权限 `0600`。
- 登录态过期后自动用已保存的账号密码重新登录，不向用户索要。
- 密码、token 绝不出现在命令行参数、stdout、stderr、日志、错误信息、文档或 Git；测试通过环境变量重定向到临时配置目录。
